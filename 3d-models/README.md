### 3D Printable Models

This directory contains the 3D model files (`.3mf`) required to assemble the N3D Crossed-Cantilever 3D printer.

### Gantry Configuration Options

The gantry component is provided in two options to accommodate different printer build volumes and user preferences:

* **Single Part:**
  * `gantry-as-one-part.3mf` — Full gantry model printed as a single piece for optimal structural rigidity on larger build plates.

* **Split into 3 Parts:**
  * `gantry-left.3mf`
  * `gantry-center.3mf`
  * `gantry-right.3mf`
  * *Note:* Use these three parts if your printer build volume cannot fit the full monolithic gantry in a single print.
